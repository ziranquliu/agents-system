## 六、启动准备

### 环境检查清单

- [ ] Python 3.11+ 已安装
- [ ] Node.js 20+ 已安装
- [ ] Docker Desktop 已安装并运行
- [ ] PostgreSQL 17 容器可用
- [ ] Redis 7 容器可用
- [ ] Qdrant 容器可用
- [ ] Git仓库已初始化

### 开发环境搭建

```bash
# 1. 克隆项目
cd D:\智能体管理\agents-system

# 2. 创建虚拟环境
cd backend
python -m venv venv
venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 配置环境变量
cp .env.example .env
# 编辑 .env 填写实际配置

# 5. 启动基础设施
cd ..
make infra-up

# 6. 执行迁移
cd backend
alembic upgrade head

# 7. 启动开发服务器
make backend-dev
make frontend-dev
```
