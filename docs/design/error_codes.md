## 1. 错误码体系

### 1.1 编码规则

```
AB-CDE-FG
│  │   └── 具体错误序号 (01-99)
│  └── 模块编号 (10-99)
└── 错误级别 (10=系统/20=业务/30=安全)
```

### 1.2 通用错误码

| 错误码 | HTTP 状态码 | 消息 | 说明 |
|--------|------------|------|------|
| 10-00-01 | 500 | 内部服务器错误 | 未预期的系统错误 |
| 10-00-02 | 503 | 服务暂时不可用 | 依赖服务不可用 |
| 10-00-03 | 429 | 请求过于频繁 | 速率限制 |
| 20-00-01 | 400 | 请求参数错误 | 参数校验失败 |
| 20-00-02 | 404 | 资源不存在 | 请求的资源未找到 |
| 20-00-03 | 409 | 资源已存在 | 创建重复资源 |
| 30-00-01 | 401 | 未认证 | Token 缺失或过期 |
| 30-00-02 | 403 | 无权限 | 权限不足 |
| 30-00-03 | 401 | Token 已过期 | 需重新登录 |

### 1.3 认证模块（10）

| 错误码 | 消息 | 说明 |
|--------|------|------|
| 10-10-01 | 用户名或密码错误 | 登录失败 |

| 10-10-03 | 无效的 Token | Token 校验失败 |
| 10-10-04 | 密码不符合安全要求 | 密码强度不够 |

## 3. 日志规范

### 3.1 日志级别

| 级别 | 说明 | 示例 |
|------|------|------|
| DEBUG | 调试信息 | SQL 查询、函数入口/出口 |
| INFO | 正常操作信息 | Agent 创建成功、用户登录 |
| WARNING | 警告 | 连接超时、重试、配额接近上限 |
| ERROR | 错误但不影响系统运行 | 模型调用失败、参数校验失败 |
| CRITICAL | 需要立即处理的严重错误 | 数据库不可用、数据损坏 |

### 3.2 日志格式

```json
{
  "timestamp": "2026-07-26T10:30:00.123Z",
  "level": "INFO",
  "logger": "app.services.model_template_service",
  "trace_id": "abc123def456",
  "user_id": "uuid",
  "workspace_id": "uuid",
  "message": "模型配置模板已更新",
  "extra": {
    "template_id": "uuid",
    "new_version": 2,
    "changed_fields": ["model_name", "api_base_url"]
  },
  "duration_ms": 45,
  "error": null
}
```

### 3.3 各模块日志关键事件

| 模块 | 关键事件（INFO） | 异常事件（ERROR） |
|------|-----------------|-------------------|
| Auth | 用户登录、登出、Token 刷新 | 登录失败、Token 过期 |
| Agent | 创建/更新/删除/状态变更 | 创建失败、状态流转异常 |
| ModelTemplate | 创建/更新/测试/绑定/同步 | 连接测试失败、同步失败 |
| Skill | 安装/卸载/更新/批量安装 | 安装失败、兼容性检查失败 |
| MCP | 注册/注销/连接测试 | 连接失败、协议错误 |
| Chat | 消息发送/接收（含 Token 数、延迟） | 模型调用异常、上下文超长 |
| Session | 创建/关闭/导出 | 会话异常关闭 |
| Token | 消耗记录、预算检查 | 预算超限 |
| Backup | 备份开始/完成/恢复 | 备份失败、恢复失败 |
| Health | 检查结果（含评分） | 检查异常、连续失败 |
| Collaboration | 任务创建/完成/超时 | 任务异常、Agent 无响应 |
| Market | 安装/上传/下载 | 安装失败 |

### 3.4 日志存储

| 环境 | 存储 | 保留期 |
|------|------|--------|
| 开发 | 控制台 + app.log | 7 天 |
| 测试 | 控制台 + test.log | 14 天 |
| 生产 | Loki + 控制台 | 30 天在线 + 90 天归档 |
